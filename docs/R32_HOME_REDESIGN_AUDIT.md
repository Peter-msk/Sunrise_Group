# Sunrise Group R32 — 메인 화면 정보구조 및 시각 재감사

## 변경 전 운영 R31 현황
- Cloudflare Workers `sg-portal-8e4c71b9` 실제 PC 1280px, 모바일 390px 전체 페이지 스크린샷 확인.
- 원래 첫 화면: 큰 Sunrise Group 로고 → 전체 폭 태양계 + 네 개 조작 버튼 → 그룹 철학 문구 → A/B/D 테마 3개 카드 → 또 다른 그룹 목표 설명 → 개발 이념 3열 → 미래 방향 배너.
- 문제 1: 기술기업 홈페이지인데 제품을 찾는 Primary Action이 첫 화면에서 낮은 우선순위, 그룹 소개 CTA 반복.
- 문제 2: A/B/D가 서로 독립적인 세 카드라서 역할 혼재, 디자인이 하나의 브랜드 경험으로 연결되지 않음.
- 문제 3: 같은 내용을 반복하고 부제마다 큰 세로 공백을 사용해 모바일에서 제품 안내까지 스크롤이 길어짐.
- 문제 4: 태양계 제어 버튼 네 개가 모바일 첫 화면을 차지함.

## R32 변경 목표
1. A: 첫 화면은 브랜드·문제해결·제품 탐색을 한 번에 설명하는 시네마틱 2열 히어로, 모바일은 텍스트 우선 1열.
2. 태양계 렌더러와 기존 장면 DOM, 8개 행성, WebGL 관련 스크립트, 제어 버튼·도움말은 보존. Native details를 통해 조작 패널을 필요 시 펼침.
3. B: PC·웹 프로그램 16개를 실제 사용자 제공 PDF PRO 개발 버전 스크린샷과 함께 간결하게 소개.
4. D: QGIS 9개를 실제 플러그인 화면이 아닌 '기능 설명용 지형 모델'임을 명시한 개념 이미지와 함께 소개.
5. 그룹 소개·목표·이념은 한 번만 핵심 메시지를 전달하도록 축약/통합하되 기존 본문 속 실무철학과 세 개발 원칙은 보존.
6. 미래 방향은 짧은 연결성 강조 영역으로 편집, 추가 외부 이미지/JS/폰트나 새 라우트 없이 구성.

- R32 전용 stylesheet `source/r32/polish.css`; 다른 33개 라우트의 DOM·JS·CSS 근거를 변경하지 않음.
- 기존 이미지 `08abfc2...png`(PDF PRO 실제 화면)와 `359581...webp`(QGIS 설명용 지형) 두 개를 홈에서 재사용, 정적 자산 23개 그대로.
- 앱 다운로드 링크/새로운 제품 상태 주장/실제 QGIS runtime PASS를 만들지 않음.
