## 이번 변경
1. /programs에서 QGIS 9개·개발 완료 6개·개발 중 3개로 바로잡음. 개발 완료는 실제 QGIS Runtime 검증 완료와 다름.
2. PC는 전체 16개 제품, 그중 상태 확인 중 3개임을 명시함.
3. 제품 선택 카드에 B TECH / D GEOSPATIAL 안내 라벨과 색상 강조선을 추가해 홈의 3테마 구성을 연결함.
4. 과도한 소개 영역 패딩과 홈 카드 이후 공백을 축소하되 주요 텍스트, 접근성, 링크를 그대로 유지함.
5. 25개 상세 페이지의 기존 구조를 바꾸지 않고 design-family에 따라 기술계/공간정보계 작업 흐름 테두리를 차등 적용함.
6. 새 이미지·폰트·네트워크 호출·추가 JS 런타임 없음.
