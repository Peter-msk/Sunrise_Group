# Sunrise Group R33 — 메인 탐색 중복 제거·모바일 가독성 4차 보완

## 근거 / 운영 R32 재감사
- 2026-11-22 작업 기준: R32 main SHA 7aa01fc8, 공식 Workers `sg-portal-8e4c71b9`.
- PC 1440px, 태블릿 768px, 모바일 390px 운영 캡처 재감사 및 R32 빌더·CSS·QA 확인.
- R32 홈 메인 Primary CTA `개발 제품 살펴보기`가 `#/programs` 중간 안내로 이동하지만 같은 메인 하단에 이미 B/PC·D/QGIS 선택이 존재함. 솔루션 발견에 한 단계 불필요한 이동이 발생.
- 하단의 `솔루션 분야 보기`도 홈 B/D 영역을 가리켜 핵심 CTA와 역할이 중복.
- 모바일 760px 이하 소개문·개발 원칙은 각각 13px/12px로 표시됐고 전체 제품 개요로 가는 명시적 링크가 B/D 카드 바로 아래에 없음.
- SPA 앵커 `#/#solutions` 및 `#/#purpose`는 기존 R32에서 실검증된 라우팅 방식이지만 sticky header에 의해 상단 일부가 가려질 수 있어 scroll-margin-top 적용 필요.

## 구현 및 소유권
1. 첫 화면 제품 CTA는 중간 페이지로 가지 않고 기존 화면의 B/D 카테고리 안내까지 바로 스크롤.
2. 히어로 하단 링크는 기존 개발 원칙 `#purpose` 영역으로 이동하도록 분업.
3. B/D 제품 카드 아래 전체 목록 링크를 별도 편집형 가로 스트립으로 제공하여 `#/programs` 경로를 그대로 이용할 수 있도록 함.
4. CSS는 `.home-v2.r32-home`으로만 소유권 제한, 새로운 글로벌 토큰/새 런타임 JS/이미지/폰트/네트워크 호출 없음.
5. 작은 화면에서 제품 설명 최소 14px, 개발 원칙 최소 13px, 주요 부속 링크 min-height 44px; 마우스·키보드 접근성 유지.
6. 목적지 `#solutions`와 `#purpose`에 고정 헤더 높이 기반 scroll-margin 적용. 기존 태양계 WebGL·상호작용·제어 4개 불변.

## 검증 및 이전 PASS 재사용
- 7개 viewport(320,390,768,1024,1440,1920,2560)에서 렌더링, 가로 넘침, 텍스트 크기, 버튼 높이, 실링크 동작 검사.
- 각 viewport에서 두 개의 deep link 스크롤이 실제 목표를 보여주고 sticky header에 가려지지 않는지 확인.
- 390px/1440px에서 `전체 제품 목록 보기`로 실제 라우팅 확인.
- 390/768/1440px 전체 화면 실제 스크린샷, 변경 없는 기존 이미지 두 개 디코딩 확인.
- R32·R31 PASS가 유효한 영역은 중복 실행하지 않고 34개 라우트/25개 상세/2개 제품군/1개 태양계 보존을 저비용 확인.
- QA 실패 및 수정 발생 시 해당 변경영향 항목만 재검증. QA·실화면 확인 전 운영 배포 금지.
