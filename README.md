## R28 변경 범위 (기존 운영 기준)

- PC 프로그램 16개와 QGIS 플러그인 9개의 카드 설명 및 상세 소개를 실제 확인된 기능 기준으로 정리한다.
- 제품별 상세 페이지에 기능 설명과 3단계 작업 흐름을 추가한다.
- Drawing Editor 상세에는 DXF·DWG 입력과 DWG 외부 변환기 필요 조건을 명시한다.
- Sunrise Finder의 마지막 공개 버전 v2.1.2와 개발 중지 상태를 분리하고, Sunrise EIASS가 운영기관의 공식 소프트웨어가 아님을 명시한다.
- 개발 상태, 공개 배포 여부, 실제 QGIS Runtime 검증을 분리해 표시한다.
- 외부 개발 제품 목록과 상세 경로를 제거하고 QGIS 카탈로그 집계·그룹 수를 9개 기준으로 갱신한다.
- QGIS 플러그인 관리 그룹의 불필요한 빈 2열 공간을 전체 폭 1열로 재배치한다.
- 36개 이미지 참조를 23개 content-addressed 정적 파일로 외부화하고 중복 payload를 제거한다.
- 각 경로의 첫 이미지 12개는 `loading=eager` + `fetchpriority=high`, 나머지 5개는 `loading=lazy`로 처리한다. 모든 이미지에 `decoding=async`와 intrinsic width/height를 지정한다.
- 3D 태양계의 9개 행성 텍스처는 홈 태양계 장면이 실제 viewport에 들어올 때만 요청한다. 다른 제품 페이지에서는 불필요한 텍스처 다운로드를 하지 않는다.
- 이미지 확대는 동일 출처의 정적 자산만 열도록 제한한다.
- R28 전용 CSS·이미지 프리뷰·제품 설명 데이터는 `source/r28/`에 격리한다. R25 원본 조각과 R27 overlay는 변경하지 않는다.

## 빌드 및 QA

```bash
npm run build
node scripts/qa-portal.cjs
```

- `scripts/assemble-r31.cjs`는 R30까지 빌드한 뒤 상세 탐색만 보완합니다. R30→R29→R28→R27 순서로 기준본을 보존합니다. `scripts/assemble-r29.cjs`는 R28을 호출하고 R29 디자인만 추가합니다. 기존 `scripts/assemble-r28.cjs`는 R27 검증 빌드를 호출한 뒤 R28의 제품 설명·레이아웃·이미지 최적화를 적용한다.
- `source/r28/products.json`은 제품 카드·상세 소개·기능·작업 흐름·검증 주의사항의 단일 콘텐츠 원장이다.
- `public/assets/r28/`는 빌드 산출물이며 Git에 별도 저장하지 않는다. 파일명은 SHA-256 기반이다.
- QA는 34개 라우트, PC 16개, QGIS 9개, 25개 상세 작업흐름, 이미지 자산 로딩·확대, PC/모바일 반응형 및 기존 내비게이션 계약을 확인한다.
- QGIS Runtime이 실제로 실행되지 않은 제품은 NOT RUN으로 표시한다. 정적/모의 테스트를 실제 QGIS 실행 PASS로 바꾸어 표현하지 않는다.

## 배포

Cloudflare Workers Static Assets를 사용한다. `npm run deploy`는 `predeploy`에서 R28 빌드·검증을 수행한 뒤 기존 Worker에 배포한다. Cloudflare 인증 및 운영 배포 권한이 필요하다.

R31은 별도 후보 브랜치에서 25개 상세의 PC·모바일 실동작 검증에 통과한 뒤 PR을 통해 main 반영 및 운영 배포합니다. 다른 Sunrise 제품 저장소와 Worker는 변경하지 않습니다.
